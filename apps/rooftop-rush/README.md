# Rooftop Rush

A side-view 2D platformer. A kid scientist accidentally caused the flood — now they have to climb floor by floor through 3 buildings (apartment → office tower → skyscraper), dodging hazards and rescuing trapped neighbors before the water catches up.

## Run locally

From the repo root:

```bash
npm run dev:rooftop-rush
```

Then open `http://localhost:3000/rooftop-rush/`.

## Controls

- **Keyboard**: ←/→ or A/D to move, Space / W / ↑ to jump.
- **Touch**: on-screen left/right/jump buttons appear automatically on touch devices.
